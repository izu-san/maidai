# 梨乃エージェントでできること

最終更新: 2026-09-28  
対象: `rino_agent` / `rino_mcp` の現行実装

## 現在利用できる機能

エージェントサービスは、ローカルの LLM（KoboldCpp 経由）と MCP ツールをつなぎ、自然言語の依頼に応じて家電操作、生活記録、状態確認を行います。現在の設定では **SwitchBot と Rino Life 連携が有効** です。

| 分類 | 機能 | 実行時の扱い |
|---|---|---|
| 室内環境 | 温度・湿度・CO2 の取得 | そのまま実行 |
| 照明 | 照明のオン／オフ | そのまま実行 |
| エアコン | 電源オン／オフ | そのまま実行 |
| エアコン | 設定温度を 16〜30℃ に変更 | 毎回承認が必要 |
| テレビ | 電源オフ | そのまま実行 |
| テレビ | 電源オン | 毎回承認が必要 |
| 玄関 | ドア・ロック状態の取得 | そのまま実行 |
| 玄関 | 施錠 | 毎回承認が必要 |
| 就寝ワークフロー | テレビをオフにしてから照明をオフ | 低リスクの定型処理として実行（施錠は含まない） |
| 生活記録 | 洗濯完了、消耗品の購入・開封・残量補正 | 明示的な依頼時に記録。Life API のイベント境界を経由 |
| 消耗品 | 一覧・残量不足の確認 | そのまま実行 |
| 消耗品 | 新規登録・管理対象からの削除 | 毎回承認が必要 |

各操作は SwitchBot API の応答で確認を試みます。確認できない場合、エージェントは「操作が完了した」と断定せず、コマンド送信のみを報告します。

## 会話・承認・セッション

- SillyTavern で「電気を消して」「洗濯終わったよ」のように入力すると、対応する家電・生活依頼は自動的に Agent へ送られます。雑談は通常会話のままです。`/rino <依頼>` も明示的な代替手段として利用できます。
- エージェントサービスの API からも、会話セッションを開始・継続できます。
- 承認対象の操作では、操作名・引数・リスクを表示して確認します。
- 承認は対象セッションと操作引数に紐付き、60 秒で失効し、一度しか使えません。
- 「はい」「お願い」「yes」「ok」などの明示的な返答で承認、「いいえ」「不要」「cancel」などで拒否できます。
- セッションの取消ができ、取消後は保留中の承認も無効になります。
- セッションと承認はメモリー上だけに保持され、サービス再起動後に自動再開されることはありません。
- 実行中の応答や結果は WebSocket で受信できます。

## イベント待機・通知

Vision、ComfyUI、OBS、システム由来のローカルイベントを受け取れます。指定イベントを待つ通知タスクを登録すると、イベント受信時に完了通知を出します。

- イベントは認証済みのローカル API 経由で受信します。
- 待機タスクには 1 秒〜24 時間の有効期限を設定できます。
- イベントの受信は、外部操作の自動実行を再開しません。通知専用です。

## 実装済みだが、現在は無効の拡張機能

以下は MCP サーバーとして実装されていますが、`rino_agent/config/mcp.yaml` で `enabled: false` のため、現状のエージェントからは利用できません。有効化と接続先設定が必要です。

| 連携先 | 実装済みの機能 | 承認が必要な操作 |
|---|---|---|
| OBS | 配信・録画状態の確認、シーン変更、配信／録画の開始・停止 | 配信開始・停止、録画開始・停止 |
| ComfyUI | 稼働状態確認、ワークフロー一覧・読込、プロンプト投入・取消、履歴取得 | プロンプト投入・取消 |
| Windows | プロセス確認、許可済みアプリの起動・終了、音量取得・変更、スクリーンショット、許可済みフォルダー内のファイル確認・起動 | アプリ起動・終了、ファイル起動 |

Windows 連携にはシェル、PowerShell、レジストリ、マウス・キーボードを操作する機能はありません。アプリとファイルパスはいずれも事前許可リストに限定されます。ComfyUI はローカルホストの HTTP 接続と指定ワークフローディレクトリに限定されます。OBS は GUI 自動操作ではなく OBS WebSocket を利用します。

## 安全設計と運用上の制約

- サービスは `127.0.0.1:8766` のローカル接続だけを受け付けます。
- `GET /health` 以外の API は Bearer トークン認証が必要です。
- MCP サーバーはエージェントサービスが所有するプライベートな標準入出力プロセスであり、HTTP 公開されません。
- 許可済みの内部 MCP サーバーとツールだけを呼び出せます。
- 操作・承認・イベントは監査ログへ記録され、ログの整合性を検証できます。
- ワークフローのチェックポイントは保存されますが、自動再開は行いません。

## 主なローカル API

| API | 用途 |
|---|---|
| `POST /agent/run` | 依頼の開始・継続 |
| `POST /agent/approve` / `POST /agent/reject` | 保留中操作の承認／拒否 |
| `POST /agent/respond` | 自然言語による承認／拒否 |
| `POST /agent/cancel` | セッションの取消 |
| `GET /agent/session/{id}` | セッション状態の確認 |
| `GET /agent/tools` | 現在許可されているツール一覧 |
| `POST /events` | ローカルイベントの送信 |
| `GET` / `POST /agent/tasks` | イベント待機タスクの一覧／登録 |
| `POST /workflows/sleep` | 就寝ワークフローの実行 |
| `GET /workflows/checkpoints` | チェックポイント一覧の確認 |
