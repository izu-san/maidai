# MaidAI 起動ハブ

プロジェクト直下で、次のいずれかを実行します。

```powershell
.\Start-MaidAI.ps1                  # 通常の文字会話: MemPalace → SearXNG → Gemma 4 → SillyTavern
.\Start-MaidAI.ps1 -Profile voice   # RVC API + EdgeTTS
.\Start-MaidAI.ps1 -Profile full    # Docker基盤→Gemma 4→SillyTavern→音声系の順で起動
.\Start-MaidAI.ps1 -Profile docker  # 登録済み Docker コンテナと Compose サービスを起動
.\Start-MaidAI.ps1 -Status          # 起動状態を確認
.\Start-MaidAI.ps1 -Stop            # ポートが判別できるサービスを停止
```

`chat` が既定です。Docker 基盤を起動後、Gemma 4（KoboldCpp）、SillyTavern、Rino Life API、Rino Agent Service の順に、各サービスのポート応答を待って起動します。すでに動いているサービスは再起動せず、応答確認だけを行います。Life API を使う前に、Rino Life の migration と消耗品初期データの投入が必要です。

## Docker を使うサービス

`Start-MaidAI.ps1` 冒頭の `$DockerContainers` に、既存コンテナの名前を登録しています。現在は `mempalace` と `searxng` が対象で、`-Profile docker` で停止中のものだけを起動します。各コンテナは公開ポートの応答を確認してから、次のサービスへ進みます。

`-Profile full` は MemPalace → SearXNG → Gemma 4（KoboldCpp）→ SillyTavern → RVC API → EdgeTTS の順で、各ポートが応答可能になるまで待機してから次を起動します。待機時間を超えるとエラーで止まり、後続サービスを起動しません。

Compose ファイルで管理するサービスを追加したい場合だけ、`$DockerProjects` に登録します。既定では Compose サービスを起動しません。

```powershell
@{ Name = '検索エンジン'; Path = 'D:\AI\検索エンジン\compose.yaml'; Services = @() }
```

`Services = @()` は Compose に定義された全サービス、`@('サービス名')` は指定サービスだけを起動します。登録後は以下で一括起動できます。

```powershell
.\Start-MaidAI.ps1 -Profile docker
```

`-Stop` は、ポートで判別できるネイティブサービスに加え、登録済みの Docker コンテナと Compose サービスを停止します。

GPT-SoVITS は起動ハブの管理対象外です。必要になった場合は、専用の手順で個別に起動してください。
